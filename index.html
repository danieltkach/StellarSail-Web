🎮 Controls

The game runs in modes — some keys do different things depending on which mode you're in.

LLock detected target / unlock
EnterToggle autopilot (when locked)
W / STelescope polar up / down
A / DTelescope azimuth left / right
, / .Frequency −1 / +1 MHz

Space (hold)Thrust
Backspace (hold)Brake

💻 System Requirements

Windows: 10 / 11 (64-bit)

Linux: x86-64 or ARM64 (Raspberry Pi 4/5)

macOS: Apple Silicon or Intel

Runtime: bundled — nothing else to install.

⚠️ First Launch: Windows Defender may show a warning because the app isn't signed. Click "More info" then "Run anyway" to install.

This is safe - it's just because I'm an independent developer. If the game becomes successful I'll be able to afford the signing that costs $400/year.
